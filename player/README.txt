PERSONAGEM FEMININO

Coloque aqui os PNGs usados quando a pessoa escolher FEMININO na tela inicial.
A pasta aceita os mesmos nomes e formatos que a pasta player/README.txt:

  player.png                         imagem estática principal
  front.png / back.png               olhando para frente / para trás
  left.png / right.png               olhando para os lados
  walk1.png / walk2.png              animação básica da caminhada
  front-walk1.png / front-walk2.png  caminhada olhando para frente
  back-walk1.png / back-walk2.png    caminhada olhando para trás
  left-walk1.png / left-walk2.png    caminhada para a esquerda
  right-walk1.png / right-walk2.png  caminhada para a direita

Os demais nomes aceitos estão listados em ../README.txt. Use PNGs com fundo
transparente. Se esta pasta estiver vazia, o jogo procura os arquivos antigos
na pasta player/; se também não encontrar imagens, usa o personagem de Canvas.
